Демо-портфель из четырёх бумаг. Каждый будний день после закрытия биржи — разбор и короткое сообщение владельцу.

!

Не является индивидуальной инвестиционной рекомендацией. Агент даёт аналитику и образовательную информацию. Решения о сделках вы принимаете сами. Модель может ошибаться: проверяйте ключевые цифры по первоисточникам. Агент не совершает сделок и не просит доступ к брокерскому счёту.

Возможности

Что умеет агент

Портфель одной строкой

«Мой портфель: SBER, LKOH, MGNT». Количество и цена по желанию (SBER:100@285). Сделки — словами.

Ежедневный брифинг

После закрытия: движение против IMOEX и сектора, обороты, гэпы, 52-недельные уровни, отсечки, проверенные новости.

Недельный обзор

Доходность против IMOEX за неделю, месяц, квартал, год; волатильность, бета, просадка, вклад позиций.

Комитет по событию

Отчёт, смена дивполитики, движение больше 15% — созывается инвесткомитет с адвокатом дьявола и оценкой.

Папка на бумагу

Отчёты, новости, цены, тезис и протоколы в ~/family-office/<ТИКЕР>/. Совместимо с ru-stocks-agent.

Приватность

Портфель хранится только на вашем компьютере и никуда не отправляется.

База знаний Obsidian

Хранилище — LLM-вики: заметки с [[ссылками]] и свойствами, хаб на каждую бумагу, конспекты документов. Откройте в Obsidian и смотрите граф.

Журнал знаний и проверка

log.md — что агент узнал и откуда. Проверка вики ищет битые ссылки, цифры без источника и противоречия.

Одно хранилище на всех

Акции, портфель, облигации и FinEx в одном Obsidian: INVEST_VAULT, общие темы и шаблоны, недельный дайджест.

Установка

Одна команда для каждой среды

Навык по открытому стандарту Agent Skills (SKILL.md). Нужен Python 3.9+, только стандартная библиотека и pypdf для PDF.

$ ./install.sh claude
